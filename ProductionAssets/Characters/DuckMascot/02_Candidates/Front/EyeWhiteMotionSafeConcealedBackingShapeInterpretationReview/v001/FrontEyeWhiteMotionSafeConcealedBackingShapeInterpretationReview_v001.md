## Recommendation

Use one **complete solid backing Shape** for each EyeWhite rather than a minimum concealed safety ring.

Reasons:

- EyeWhite is semantically one continuous soft white field;
- a complete backing removes permanent EyeDark-shaped holes;
- it supports restrained EyeDark translation without exposing background;
- it provides a stable future eyelid-mask surface;
- it avoids topology that changes whenever the motion envelope changes;
- the concealed region remains clearly distinguishable as Production Construction.

This recommendation does not define a final vector path or hidden RGB.
